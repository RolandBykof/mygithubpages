Lammio Reader – Quick Guide

Version 1.0.0. This guide assumes you're already familiar with the basics of a DAISY player, so it doesn't explain navigation levels, heading structure, or the table of contents from scratch. It only covers what is specific to this app.

1. Importing books into the local library

The bottom of the library screen has a row of buttons. In local mode, the first two are import buttons: Import from files and Import over Wi-Fi. Both end up in the same place: the book is added to the device's own library.

Supported file types are a DAISY book as a ZIP archive, MP3, EPUB, PDF, Word documents (.docx), and plain text files (.txt). The contents of a ZIP archive are detected automatically, so both audio books and text-based DAISY books go through the same route.

Import from files

This button opens iOS's own file picker. From there you can choose files from anywhere the Files app can see, including iCloud Drive or another cloud provider's folder.

You can select several files at once. The app imports them one at a time in a queue, and a status message on screen shows what's currently in progress. Each finished book triggers a notification with the book's title. If a book is already in the library, you're told so and it isn't imported again.

Import over Wi-Fi

This method is meant for files that are on a computer. Nothing needs to be installed on the phone, and you don't need to move the files to the cloud first.

  1. Make sure the phone and the computer are on the same Wi-Fi network. Mobile data doesn't work, and if Wi-Fi isn't available the app tells you directly.
  2. Tap Import over Wi-Fi. The app starts a small server on the phone and shows an address. Next to the address is a Copy address button, which lets you put it on the clipboard and, for example, send it to yourself as a message.
  3. Open the address in a browser on the computer. The page offers two options.
  4. Option 1: copy the files in your file manager (Command+C or Ctrl+C), go to the drop area on the page and paste them (Command+V or Ctrl+V). Option 2: choose the files with the page's file picker button and press Send to phone.
  5. Keep the phone's screen on for the whole transfer. The app itself prevents the screen from turning off, but if you leave the app, iOS stops the server and the browser reports that the transfer failed.

The screen shows an activity log with timestamps of what the server has received, plus a counter of books received so far. If the transfer doesn't go through, the browser page has a Test connection to phone button. The test sends a small request and tells you whether downloads can reach the phone.

Deleting a book

Deleting means the book is removed from the phone entirely. It isn't moved to a trash folder and you aren't asked to confirm, so you'll need to import it again if you want it back.

You can delete a single book in two ways, depending on whether you use VoiceOver.

With VoiceOver: swipe up on the book

Each book row has a custom action defined for it — the same mechanism VoiceOver uses to offer actions on, for example, email messages.

  1. Move to the book you want to delete in the library list. VoiceOver reads the book's title and details.
  2. Swipe up or down with one finger. VoiceOver says Remove from library.
  3. Double-tap. The book is deleted immediately.

For now there's only one action, so a vertical swipe always lands on the same option. Make sure you're on the right book before double-tapping: there's no confirmation, and the deletion can't be undone.

The three-dot button at the end of the row is deliberately hidden from VoiceOver, since deletion is already available as a vertical swipe.

Without VoiceOver: the menu at the end of the row

Each book row ends with a three-dot button that opens a menu. The menu has one entry, Remove from library. Choosing it deletes the book right away.

Deleting several books at once

Selection mode is opened from the Edit button in the top-left corner of the library screen.

  1. In selection mode, every book row is a switch. VoiceOver reads the book's title and the switch's state, and a double-tap selects the book or clears the selection.
  2. The screen title continuously shows how many books are currently selected.
  3. At the bottom is a delete button that removes every selected book. It only becomes available once at least one book is selected.

Selection mode is closed from the same top-left button, which now reads Done. Closing it doesn't delete anything — simply leaving selection mode just forgets the selection.

2. Switching between the local library and DAISY Online

The library screen has two modes: Local files and DAISY Online. You switch between them with a button in the bottom bar, placed after the import buttons and before the settings button. The button's label always tells you where it leads: in local mode it reads DAISY Online, and in online mode it reads Local files.

The screen title changes at the same time, so you can also check the current mode by moving to the title.

Switching changes more than just the list's contents:

  • In local mode, the bottom bar has the import buttons, and there's an Edit button in the top-left corner.
  • In DAISY Online mode, the first button in the bottom bar is Add service, and there's no Edit button, since multi-selection only applies to books on the device.
  • The settings button is in the same place at the end of the bottom bar in both modes.

DAISY Online mode shows a list of the services you've added. Opening a service signs in and shows its shelf.

Adding a service

Tap Add service in the bottom bar. A form opens with a Service picker at the top, set by default to New service…, followed by fields for its name and address, then your username and password, and a Test connection / Save button row.

You can add any DAISY Online service you have access to — for example one run by a library or organisation, in any country. Not every service behaves in exactly the same way, so this is a case of trying it rather than a guarantee: the app may not work correctly with your particular service, even if every field is correct.

Service name
Any name you choose. It's only used to identify the service in your own list — for example on the DAISY Online screen and when confirming a removal.
Service address
The full web address of the DAISY Online service, given to you by its provider. It must be typed out in full.

Fill in the username and password as usual, then optionally choose Test connection to make sure the details work before saving. Save is only available once every field has a valid value.

Once a service you've added this way is saved, it also appears in the Service picker the next time you add a service — so if you ever need to add a second account for the same library, you can pick it by name without typing the address again.

3. Long-pressing a seek button

At the bottom of the player, on either side of the play button, are the seek buttons: back on the left, forward on the right. They have two different behaviours.

Short tap

A tap moves according to the current navigation level — either 30 seconds, or to the next or previous heading at the level you've chosen. The button's screen-reader name tells you which one is active, so you can check it just by touching the button.

Long press: jump by minutes

Holding a button down for about half a second starts a minute picker. The app begins reading numbers aloud once a second, in this order:

1, 2, 5, 10, 20, 30, 40, 50, 60.

When you let go, the player jumps that many minutes in the button's direction — whichever number you last heard. So if you hold the forward button, hear the numbers up to ten, and let go, the book moves forward by ten minutes. The numbers are spoken as plain digits with no unit, since the unit is always minutes.

The list stops at 60, so the longest possible jump from a single press is one hour. Lifting your finger before the first number does nothing, and a tap that follows a long press won't accidentally trigger a normal seek.

With VoiceOver the gesture is double-tap and hold: tap twice and leave your finger on the screen after the second tap. This works in both the audio player and the text-to-speech player, and behaves the same way in both directions.

Note that a long press means something different on the play button in the middle: there, it starts or stops the sleep timer.

4. Speed shortcut

Above the play button are two controls side by side: navigation level on the left, speed on the right. To a screen reader they're adjustable elements, so you change the value by swiping up and down. Plus and minus buttons are also visible on screen.

The speed control also has a shortcut. A long press on the control — double-tap and hold with VoiceOver — jumps the speed straight to whatever value you've set as the shortcut in settings. The new speed is announced out loud right away, since a value change otherwise isn't reliably reported to a screen reader. The control's screen-reader hint reminds you of this gesture.

The shortcut is meant for stepping away from normal listening speed briefly — for example to skim through a passage quickly and then step back down gradually. It's a separate setting from the default speed, which sets what speed a book starts at.

The available speeds depend on which player you're listening with:

  • Audio books: 0.75× to 3.0×, in steps of 0.25.
  • Text-to-speech: 0.25 to 1.0, in steps of 0.05.

Each player has its own shortcut setting. The audio book shortcut is set in Player settings, and the text-to-speech shortcut in Text-to-speech settings.

5. Settings

Settings open from the last button in the library screen's bottom bar, or from the top-right corner of the player. The top level has four entries: Language, Text to speech, Player, and About.

Every value control in Settings works the same way as the player's controls: to a screen reader they're sliders, changed by swiping up and down. A change is saved immediately; there's no separate save button.

Language

Languages are shown in the list under their own names.

Text to speech

This screen applies to text-based books, which are read aloud by a synthetic voice.

Synthesizer voice
Browse the voices installed on the device. The list shows every voice on the device, grouped by language, with a language tag after each voice's name. If you open settings while a book is open, the heading reads This book's synthesizer, and the choice only applies to that open book. Without an open book, you're changing the general default.
Match voice to book language
A switch. When on, the app picks a voice based on the book's language, so a book in a foreign language isn't read with a Finnish voice.
Default speech rate
The speed a book starts at. Used until you set a speed for that particular book.
Speed shortcut
The speech rate the player jumps to on a long press of the control. See section 4.
Sentence pause
Adds a brief silence after every sentence. Options range from Off to 0.2–1.0 seconds in tenth-of-a-second steps. Especially useful at fast speech rates.

Player

This screen covers the player's defaults and the library's sort order.

Text player navigation level
The level a text-based book opens at: 30 s, Sentence, Heading, or Page.
Audio player navigation level
The level an audio book opens at: 30 s, Level 1, Level 2, Level 3, or All.
Default speed
The speed an audio book starts at. Used until you set a speed for that particular book.
Speed shortcut
The speed the player jumps to on a long press of the control. See section 4.
Multi-DAISY default mode
For books that contain both audio and text: whether they open as an audio book or with text-to-speech. You can also switch this mid-book with a long press on the table-of-contents button.
Sort publications
The library's sort order: Alphabetical or Recently listened to. A change reorders the list immediately.
Reset to default after a delay
If you change the navigation level during playback, it reverts to the default after this amount of time unless you use the buttons again. Options: Never, 10, 20, or 30 seconds. You're notified when it reverts.
Default sleep timer duration
How long the sleep timer runs for when you long-press the play button. Options: 15, 30, 45, or 60 minutes. While the timer is running, the bottom-left corner of the player shows the time left and a button to cancel it.

About

Opens a dialog with the app's name, its version number with build number, and the copyright notice. Worth mentioning the version number if you contact support about a problem. Closed with the Close button.
