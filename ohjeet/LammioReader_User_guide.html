Lammio Reader – user guide

Lammio Reader is a Windows program for listening to DAISY books and for making audio books. With it you can:

  • listen to DAISY audio books and move in them by heading, by page and by time
  • listen to DAISY text publications, which the program reads aloud with the speech synthesizer of Windows
  • make an audio book from an English e-book (EPUB, Word or PDF) with speech synthesis, either as a DAISY book or as MP3 files.

The program is made for screen reader users, and everything is done with the keyboard. The program tells the screen reader the result of every action, for example the name of a heading, the level or the speed.

1. What is a DAISY book?

DAISY (Digital Accessible Information System) is an international standard for accessible books. It is maintained by the DAISY Consortium and is widely used by libraries and organisations that serve people who are blind, partially sighted or have other reading difficulties. For example, many libraries for the visually impaired lend their audio books as DAISY books.

An ordinary audio book is one long recording, or a set of files that you can only play from the start to the end. A DAISY book is different:

  • You can move by headings. The book has a table of contents built from its headings. You can jump straight to a chapter or a section, and to the next or previous heading, in the same way as you move through a document with a screen reader.
  • You can move by pages. If the book is made from a printed book, it often knows the page numbers of the printed book. You can then go straight to, for example, page 120, just like a sighted reader who opens the printed book.
  • The player remembers your place. When you close the book and open it again, listening continues where you stopped.

A DAISY book is a folder of files: a table of contents, audio files (usually MP3) and files that link the text to the audio. Books are usually delivered as one ZIP file, which is a compressed package of these files. You do not need to open or understand the files yourself. Lammio Reader takes care of them when you import the book.

There are two kinds of DAISY books:

  • Audio books contain recorded or synthetic speech. Most DAISY books are like this.
  • Text publications contain only text, without audio. Lammio Reader reads them aloud with the speech synthesizer of Windows. See Text publications.

Lammio Reader supports the two common versions of the standard, DAISY 2.02 and DAISY 3. You do not need to know which version a book is.

2. Installation

Lammio Reader is delivered as a ZIP file, LammioReader.zip. The program is not installed in the usual way. Instead, you extract the ZIP file on your computer and start the program from the extracted folder.

Download Lammio Reader for Windows (ZIP)

The ZIP file contains the program (LammioReader.exe), this user guide (user_guide.html), the Finnish user guide (kayttoohje.html), and DLL files and folders that the program needs to run. Do not move or delete any of them. The speech synthesis voices used for creating audio books are not in the ZIP file. The program downloads them from the internet the first time a voice is used (see Creating an audio book from an e-book).

Unblocking the ZIP file

If you got the ZIP file from the internet or as an email attachment, unblock it first. Then Windows does not warn about every file separately:

  1. In File Explorer, select the ZIP file and open the context menu by pressing Shift+F10 or the Applications key.
  2. Choose Properties. At the bottom of the General tab there is a check box called “Unblock”. Check it with the space bar and press OK. If there is no such check box, the file is not blocked.

Extracting the ZIP file

  1. Open File Explorer and go to the folder where the ZIP file is saved, usually the Downloads folder.
  2. Select the ZIP file with the arrow keys.
  3. Open the context menu by pressing Shift+F10 or the Applications key.
  4. Choose “Extract All” and press Enter. The Extract Compressed (Zipped) Folders window opens.
  5. The window tells you which folder the files are extracted to. You can accept the suggestion or choose another place with the Browse button, for example the Documents folder. Keep the option “Show extracted files when complete” checked.
  6. Press the Extract button. Extracting takes a moment, because the extracted program takes about 380 megabytes.

Always extract the ZIP file before starting the program. If you open LammioReader.exe directly from inside the ZIP file, the program does not work correctly.

Starting the program

  1. When extracting is complete, the extracted folder opens in File Explorer. It contains the folder LammioReader. Open it by pressing Enter.
  2. Select the file LammioReader.exe and press Enter. The program starts in the library view. The first start can take about ten seconds.

When you start the program for the first time, Windows may show the message “Windows protected your PC”. This happens because the program is not signed with a publisher certificate. It does not mean that the program is harmful. Choose “More info” and then “Run anyway”. With a screen reader, press Tab until you hear “More info, link” and press Enter, then press Tab until you hear “Run anyway, button” and press Enter.

A shortcut on the desktop

You can start the program more easily with a desktop shortcut:

  1. In the LammioReader folder, select the file LammioReader.exe.
  2. Open the context menu by pressing Shift+F10. In Windows 11, first choose “Show more options”.
  3. Choose “Send to” and then “Desktop (create shortcut)”.

Updating and removing

  • To use a new version, extract the new ZIP file over the old folder, or delete the old folder first. Your books and settings are kept, because they are in a different folder (see Where books and settings are kept).
  • To remove the program, delete the LammioReader folder. If you also want to remove your books and settings, delete the folder %USERPROFILE%\.lammio_reader as well.

3. Starting the program

The program opens in the library view. The focus is in the book list, and you can browse the books with the Up and Down arrow keys. If the library is empty, the program says: “The library is empty. Press Ctrl+O to import a book.”

The first time you start the program, its language is English. You can change the language to Finnish in the Settings menu, under Language. The choice is saved.

4. Importing a book into the library

Books are imported as ZIP files. The program extracts the book into its own library, so you do not need the original ZIP file after importing.

  1. In the library, press Ctrl+O. You can also choose “Import book from ZIP file” in the File menu, or press the button of the same name.
  2. The Import a DAISY book window opens. Select one or more ZIP files and press Enter. To select several files, hold down the Ctrl key while you select them.
  3. The Extracting book window opens. It says, for example, “Extracting the book book.zip, please wait.” If you import several books, the window also tells you which book is being extracted, for example (2/3).
  4. The screen reader tells you the progress every ten percent, for example “40 % extracted.” Extracting a large book can take a while. You cannot use the rest of the program while extracting, and you cannot close the window by accident.
  5. When extracting is complete, the window closes and the program says, for example, “Imported: Book title.” The new book is selected in the book list.

Both DAISY audio books and DAISY text publications can be imported. The book must be a DAISY 2.02 book (it contains the file ncc.html) or a DAISY 3 book (it contains an .opf file and an .ncx file). A ZIP file that contains, for example, only MP3 files is not a DAISY book.

You cannot import the same book twice. If the book is already in the library, the program says: “The book … is already in the library.”

5. The library

The books are in alphabetical order. For every book you hear the title, the author, the duration and how much of the book you have listened to, for example “Poison, Author Name, 8 h 12 min, 35 % listened”. For a text publication you hear “text publication” and how much of it has been read.

  • Enter opens the selected book and starts playback from where you stopped last time.
  • Ctrl+O imports new books.
  • Delete deletes the selected book. The program asks you to confirm first. Choose Yes if you want to delete the book. Deleting removes the book's files and its listening position.

6. Listening to a book

When the book opens, the program says the title of the book and the level. If you have listened to the book before, it also tells you where listening continues, for example “Continuing from 1:24:10.” Playback starts at once.

  • Space: play and pause.
  • Up arrow and Down arrow: change the navigation level. See Navigation levels.
  • Left arrow and Right arrow: move back and forward on the selected level.
  • + and -: make the speech faster and slower. The speeds are 0.5, 0.75, 1, 1.25, 1.5, 1.75, 2, 2.5 and 3. The pitch of the voice does not change when the speed changes.
  • N: back to normal speed (1). The program says “Speed 1, normal”.
  • U and D: volume up and down in steps of 10 percent. The program says the new value, for example “Volume 70 %”. The lowest value is 10 % and the highest 100 %, so the sound cannot disappear completely by accident. The volume is the same for all books, and the program remembers it.
  • T: go to time.
  • P: go to page.
  • I: tells the elapsed and remaining time, for example “Elapsed 1:24:10, remaining 6:47:50.”
  • Esc: stops listening and returns to the library.

The program remembers the listening position and the speed of every book. The position is saved every few seconds while you listen, and always when you return to the library or close the program.

The listening view also shows the current heading, the level, the speed, the position in the book, for example “Position: 1:24:10 / 8:12:00”, and the volume.

7. Navigation levels

A DAISY book has a structure, much like the table of contents of a printed book. Depending on the book, you can move through it on several levels: for example by chapter, by subheading or by page. The levels available vary from book to book. A simple book may have only one heading level, while a textbook can have several heading levels and page numbers.

The level decides where the Left and Right arrow keys move. The Up and Down arrow keys change the level, and the program says the name of the new level. The levels are in this order:

  1. Time, 30 seconds by default. The arrow key moves the chosen time back or forward. The program does not say anything about the move; playback simply continues from the new place. To hear where you are, press I. You can change the length of the move in the Settings menu. A book always opens on this level.
  2. Level 1, level 2 and so on. The arrow key moves to the previous or next heading, and the program says the name of the heading. Level 1 contains the main headings, such as chapters. Level 2 also stops at level 1 headings, level 3 at headings of levels 1 and 2, and so on. There are as many heading levels as the book has.
  3. Page, if the book has page numbers. The arrow key moves to the previous or next page.

After the last level, the Up or Down arrow key returns to the first level.

When you press the Left arrow on a heading or page level, and more than 3 seconds have passed since the beginning of the heading, the program returns to the beginning of the same heading. Press the Left arrow again at once to go to the previous heading.

At the beginning of the book the program says “Beginning of the book”, and at the end “End of the book”. If there are no more items on the level, it says “No more items on this level”.

8. Go to time and go to page

Go to time (T)

  1. While listening, press T. The Go to time window opens. It also tells you the length of the book.
  2. Type the time with four digits: the first two are hours and the last two are minutes. For example 0130 is 1 hour 30 minutes and 0005 is 5 minutes.
  3. Press Enter. Playback continues from that time.

If the time is invalid or longer than the book, the window stays open and the screen reader tells you the error at once. Correct the time and press Enter again. Esc closes the window without moving.

Go to page (P)

  1. While listening, press P. The Go to page window opens. The name of the field tells you the first and last page, for example “Page (1-245)”.
  2. Type the page number and press Enter.

If the page is not found, the window stays open and tells you so. If the book has no page numbers, the program says “The book has no page numbers.”

9. Text publications

A text publication is a DAISY book that contains only text, without recorded audio. Lammio Reader reads it aloud with the speech synthesizer of Windows, so you can listen to it like an audio book. You import and open a text publication in the same way as an audio book.

Listening works almost in the same way as with audio books, with these differences:

  • The first navigation level is sentence instead of time. The Left and Right arrow keys move one sentence back or forward. The heading and page levels work as in audio books.
  • A text publication has no time, so T (go to time) does not work. Move by heading or by page instead.
  • I tells you how much of the book has been read, as a percentage.
  • K and M raise and lower the pitch of the speech synthesizer. These keys only work in text publications.
  • When you pause and continue, the sentence is read again from its beginning.

You can choose which speech synthesizer voice reads text publications in the Settings menu, under Speech synthesizer. The menu lists the voices installed in Windows. The choice is saved. To add more voices, use the speech settings of Windows (Settings, Time and language, Speech).

10. Creating an audio book from an e-book

Lammio Reader can make an audio book from an English EPUB, Word (DOCX) or PDF book with speech synthesis. The book must be in English, because the speech synthesis voices are English voices and read other languages badly. The speech synthesis runs on your own computer, so the book never leaves your machine. Only the voice itself is downloaded from the internet the first time you use it.

For the finished audio book you can choose one or more of these:

  • add it to the Lammio Reader library, so that you can listen to it at once
  • save it as a DAISY book in a ZIP file, which you can save wherever you like, copy to other DAISY players or give to someone else
  • save it as MP3 files in a ZIP file, for example for an ordinary MP3 player.
  1. Press Alt and choose “Create audio book” in the File menu. The Create audio book window opens.
  2. Press the “Choose book” button and choose an EPUB, DOCX or PDF file. The title and author of the book are filled in from the book's information. You can change them.
  3. Choose a voice from the Voice list. The first five voices have a clear license. If the name of the voice ends with “not downloaded yet”, press the “Download voice” button next to the list. The screen reader tells you the progress of the download. A voice is about 63 megabytes and is downloaded only once, and downloading needs an internet connection. If you do not download the voice yourself, it is downloaded automatically when you listen to a sample or start creating.
  4. Before a voice is used for the first time, the license window of the voice opens. The focus is in the license field, which you can read with the arrow keys. The beginning of the window tells you whether the voice may be used commercially, and after that comes the voice's own license file. Choose “I accept” if you accept the license. If you choose “I do not accept”, the voice is not downloaded or used. You are asked about each voice only once. The “Show license” button shows the license of the selected voice again.
  5. If you want, you can change the speech rate, the pauses (after a comma, semicolon, colon, sentence, paragraph and heading) and the audio quality. See The settings below. The “Listen to sample” button plays a sample of the selected voice.
  6. In the “Finished audio book” group, choose what is done with the book. The group has three check boxes, and you can check one, two or all three. Check or uncheck a box with the space bar.
    • “Add to the library” (checked by default): the book is added to the Lammio Reader library, and you can move in it by heading and by page.
    • “Save the DAISY book as a ZIP file”: the book is saved as a DAISY book in one ZIP file. The program asks where to save the file and suggests the title of the book as its name. You can copy the file to other DAISY players or apps, give it to someone else, or import it into the Lammio Reader library later with Ctrl+O.
    • “Save the MP3 files as a ZIP file”: the program makes a ZIP file that contains only MP3 files, for example for an ordinary MP3 player. Every chapter is its own file, for example 001 Introduction.mp3, so the player plays them in the right order. The files also contain the title of the book and the chapter. The program asks where to save the ZIP file.
    If nothing is checked, the program asks you to check at least one box. Your choices are kept for the next time.
  7. Press “Start creating”. The screen reader tells you the progress every ten percent. If you do not want to hear the progress, uncheck “Announce progress with the screen reader”.
  8. When the book is ready, the window closes and the program says, for example, “The audio book Book title is ready and was added to the library. Duration 6 min. Press Enter to listen.” The new book is selected in the book list. If you saved a DAISY or MP3 ZIP file, the program also tells you where the file was saved.

Creating can take a long time if the book is long. On a normal laptop, creating is many times faster than reading the book aloud: a 10-minute book takes about a minute, and a long novel can take an hour or more. You can hide the window by pressing Esc or the “Close” button, and creating continues in the background. Meanwhile you can listen to other books. You get the window back by choosing “Create audio book” again. “Cancel creating” stops the creation.

Your choices are saved when you start creating, so they are ready the next time.

The voices

The Voice list always contains these five voices. They were trained on public domain recordings, so they can be used for audio books, also books that are shared with others.

en_US-ljspeech-medium
American English, female voice.
en_US-kristin-medium
American English, female voice.
en_US-norman-medium
American English, male voice.
en_US-john-medium
American English, male voice.
en_GB-cori-medium
British English, female voice. It was trained on about 24 hours of recordings from LibriVox audio books and was made for reading long texts, so it is a good first choice for many books.

Most other English voices of the same voice library are based on a voice whose recordings may only be used for research. That is why they are not offered. If you copy another English Piper voice (an .onnx file and its .onnx.json file) into the voice folder (see Where books and settings are kept), it appears after the five voices, and the program warns you that its license has not been verified and asks you to confirm before it is used. Some of these voices have several speakers; then you choose the speaker from the Speaker list.

Choosing a voice

The voices differ: some are female and some male, they speak American or British English, and they differ in clarity and style. No voice is best for everyone; the right voice depends on the book and the listener.

That is why it is worth trying several voices, or even all of them, before you make a long book:

  1. Make a small test file, for example a Word document into which you copy a heading and a few paragraphs from the book. A small file becomes an audio book quickly.
  2. Make an audio book from the test file with every voice you want to try. Change the title of the book to, for example, the name of the voice, so that you can tell the versions apart in the library.
  3. Listen to the versions and choose the voice that sounds clearest and most pleasant to you. Try the speech rate and the pauses at the same time.
  4. Delete the test books from the library with the Delete key and make the real book with the voice you chose.

The “Listen to sample” button gives you a quick idea of a voice, but the sample is only a couple of sentences. Listening to real text tells you better how the voice suits long listening.

The settings

The Create audio book window has these controls, in this order. All choices except the book, title and author are saved when you start creating, and they are ready the next time.

E-book and the “Choose book” button
The EPUB, DOCX or PDF file that the audio book is made from.
Book title and Author
Filled in from the information of the book. They are saved in the audio book, and the title is shown in the library and suggested as the name of the ZIP files.
Voice, and the “Listen to sample”, “Download voice” and “Show license” buttons
The speech synthesis voice. See The voices.
Speaker
Only for voices that have several speakers. For the five voices offered by the program the list says “Single speaker voice” and cannot be changed.
Speech rate
How fast the voice reads: 0.75, 0.9, 1, 1.1, 1.25 or 1.5 times the normal rate. The default is 1. You can also change the speed later while listening, with + and -.
Comma pause, Semicolon pause and Colon pause
Extra silence after these punctuation marks, from 0.0 to 5.0 seconds. The default is 0.2 s. With 0.0 s the sentence is read in one go, which often sounds the most natural.
Sentence pause
Silence between sentences. The default is 0.6 s.
Paragraph pause
Silence at the end of a paragraph. The default is 0.8 s.
Heading pause
Silence after a heading, so that you hear clearly where a new chapter or section begins. The default is 2.0 s.
Audio quality
The bit rate of the MP3 files: 32 (small file), 48, 64 (recommended), 96 or 128 kbit/s (best quality). The recommended value is good for speech. A higher value gives larger files but hardly any audible difference. The same quality is used for the library, the DAISY ZIP file and the MP3 ZIP file.
The “Finished audio book” group
Three check boxes: “Add to the library”, “Save the DAISY book as a ZIP file” and “Save the MP3 files as a ZIP file”. Check at least one. When you press “Start creating”, the program first asks where to save each ZIP file you chose, the DAISY file first and then the MP3 file. If you cancel a save window, creating does not start. The DAISY and MP3 files must have different names; if you give the same file for both, the program warns you and creating does not start.
Announce progress with the screen reader
When this is checked, the screen reader speaks the progress of the creation every ten percent, even when the focus is on another control. Important messages, such as the book being ready or an error, are always spoken.
Start creating, Cancel creating and Close
“Start creating” starts, “Cancel creating” stops the creation, and “Close” hides the window while creating continues in the background.

EPUB books

The program uses the table of contents of the EPUB and the headings in the text. Most published EPUB books work without any changes.

Word books

You get the best result from a Word document whose headings are made with Word's heading styles (Heading 1, Heading 2 and so on). Then the chapters and heading levels of the audio book are exactly the same as in the book. The styles work in every language version of Word.

If the headings are made only by making the text bigger and bold, the program works out the headings from the font size, bold text and numbering (for example 1.2.1). The result is usually good, but sometimes a heading can go wrong, in the same way as in PDF books.

PDF books

A PDF file usually has no information about the structure of the book, so the program works out the headings from the font size and numbering (for example 1.2.1). That is why the headings are not always as exact as in EPUB books. The program removes the headers, footers and page numbers of the pages from the text, so that they are not read on every page.

  • If the PDF contains the page numbers of the printed book, they are saved in the audio book. Then you can go to a page with the P key, and the navigation levels also include the Page level.
  • Scanned PDF files, whose pages are only pictures, cannot be made into audio books. Then the program tells you that no readable text was found in the PDF.

Books without headings

If the book has no headings, the program divides it into parts of roughly equal length. Very long chapters are also divided, so that no single audio file becomes too large.

Listening without a DAISY player

If you want to listen to the book on a device that only plays MP3 files, such as an MP3 player or a phone, check “Save the MP3 files as a ZIP file” in the “Finished audio book” group. Extract the ZIP file and copy the MP3 files to the device. An MP3 player cannot use the table of contents or move by pages; you can only move from one file, that is one chapter, to the next.

11. Menus and settings

Alt opens the menu bar. There are three menus:

  • File: Import book from ZIP file, Create audio book, Delete book and Exit.
  • Settings:
    • Language: Finnish (Suomi) or English.
    • Time skip: 10 seconds, 30 seconds, 1 minute or 5 minutes. This is the length of the move on the Time level.
    • Speech synthesizer: the Windows voice that reads text publications.
    The choices are saved and take effect at once, also while you are listening.
  • Help: Keyboard shortcuts (a list of the keys) and About (the version of the program).

Importing and deleting books only work in the library. If you try them while listening, the program says: “Press Esc to return to the library first.”

13. Solving problems

The program does not start
Make sure that you extracted the whole ZIP file and that you start LammioReader.exe from the extracted folder, not from inside the ZIP file. The first start can take about ten seconds. If an antivirus program blocks the program, ask your IT support to allow it.
“The audio engine was not found.”
The file libmpv-2.dll is missing from the program folder. Without it you can import books but not listen to them. The file is in the ZIP package, so extract the ZIP file again and start the program from the extracted folder. If an antivirus program has removed the file, ask your IT support to allow it.
“No speech synthesizer was found, so text publications cannot be read.”
Windows has no speech synthesizer voices installed. Add a voice in the speech settings of Windows (Settings, Time and language, Speech). Audio books work without it.
“Creating audio books is not available.”
Files that speech synthesis needs are missing from the program folder. Extract the ZIP file again, or ask the supplier of the program for help.
“Downloading the voice failed” or “The license file of the voice (MODEL_CARD) could not be downloaded”
The first download of a voice needs an internet connection. Check the connection and press “Download voice” again.
Creating the audio book fails, and the error message says “No readable text was found in the book”
No readable text was found in the book. Usually the reason is a scanned PDF file whose pages are only pictures. Such a file cannot be made into an audio book.
Creating the audio book fails for another reason
The full error message is copied to the clipboard. Paste it into an email with Ctrl+V and send it to the supplier of the program.
The table of contents of a created audio book is wrong or has only one item
The headings of the book are not marked as headings. In a Word document, use the heading styles. See Creating an audio book from an e-book.
A word is pronounced wrongly in a created audio book
Synthetic voices sometimes mispronounce names, foreign words and rare abbreviations. Try another voice, or write the word in the book the way it is pronounced.
“The file is not a valid ZIP file.”
The file is damaged or it is not a ZIP file. Download the book again.
“The ZIP file has no DAISY book.”
No ncc.html file or .opf file was found in the ZIP file, so it is not a DAISY book.
“The book has no audio and no readable text.”
The book contains neither audio nor text that the program could read.
“The file … is missing from the book.”
An audio file or another file is missing from the book. Delete the book and import it again from an intact ZIP file.

14. Where books and settings are kept

%USERPROFILE% means your own user folder, usually C:\Users\your name. You can type the paths below into the address bar of File Explorer.

  • The extracted books are in the folder %USERPROFILE%\.lammio_reader\kirjat.
  • The listening positions, speeds, language, time skip, volume, audio book creation choices and accepted voice licenses are in the file %USERPROFILE%\.lammio_reader\asetukset.json.
  • The downloaded speech synthesis voices and their license files are in the folder %USERPROFILE%\.lammio_reader\aanet. One voice takes about 63 megabytes.

When you move to a new computer, you can copy the whole .lammio_reader folder with you. Then your books, listening positions and downloaded voices move too.
