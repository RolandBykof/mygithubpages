Lammio Reader – user guide

Lammio Reader is a Windows application for listening to DAISY audio books and for creating audio books. With it you can:

  • listen to DAISY audio books and move in them by headings, pages and time
  • make an audio book from an English e-book (EPUB, Word or PDF) with speech synthesis, either as a DAISY book or as MP3 files.

The application is made for screen reader users, and everything is done with the keyboard. The application tells the screen reader the result of every action, for example the name of a heading, the level or the speed.

1. Installation

Lammio Reader is delivered as a ZIP file, for example LammioReader.zip. There is no separate installer: you extract the ZIP file on your computer and start the application from the extracted folder. You do not need Python or any other programs.

Extracting the ZIP file

  1. Open File Explorer and go to the folder where the ZIP file was saved, usually the Downloads folder.
  2. Select the ZIP file with the arrow keys.
  3. Open the context menu with Shift+F10 or the Applications key.
  4. Choose “Extract All” and press Enter. The Extract Compressed Folders window opens.
  5. The window shows the folder the files are extracted to. You can accept it or choose another place with the Browse button, for example your Documents folder. Keep “Show extracted files when complete” checked.
  6. Press the Extract button. Extracting takes a moment, because the application is about 410 megabytes.

Always extract the ZIP file before starting the application. If you open LammioReader.exe directly inside the ZIP file, the application does not work properly.

Starting the application

  1. When the extraction is done, the extracted folder opens in File Explorer. It contains the LammioReader folder. Open it by pressing Enter.
  2. Select the file LammioReader.exe in the folder and press Enter. The application starts in the library view.

The first time you start the application, Windows may show the message “Windows protected your PC”. This happens because the application is not signed. Choose “More info” and then “Run anyway”.

Desktop shortcut

A desktop shortcut makes the application easier to start:

  1. Select the file LammioReader.exe in the LammioReader folder.
  2. Open the context menu with Shift+F10. In Windows 11, choose “Show more options” first.
  3. Choose “Send to” and then “Desktop (create shortcut)”.

Updating and removing

  • To use a new version, extract the new ZIP file over the old folder, or delete the old folder first. Your books and settings are kept, because they are in a different folder (see Where books and settings are stored).
  • To remove the application, delete the LammioReader folder. If you also want to remove your books and settings, delete the folder %USERPROFILE%\.lammio_reader as well.

2. Starting the application

The application opens in the library view. The focus is in the book list, and you can browse the books with the Up and Down arrow keys. If the library is empty, the application says: “The library is empty. Press Ctrl+O to import a book.”

The first time you start the application, the language is English. You can change the language to Finnish (Suomi) in the Settings menu, under Language. The choice is saved.

3. Importing a book into the library

Books are imported as ZIP files. The application extracts the book into its own library, so you do not need the original ZIP file after the import.

  1. In the library, press Ctrl+O. You can also choose “Import book from ZIP file” in the File menu or press the button with the same name.
  2. The Import a DAISY book window opens. Select one or more ZIP files and press Enter. To select several files, hold down Ctrl.
  3. The Extracting book window opens. It says, for example, “Extracting the book book.zip, please wait.” If you import several books, the window also tells which book is being extracted, for example (2/3).
  4. The screen reader announces the progress every ten percent, for example “40 % extracted.” Extracting a large book can take a while. You cannot use the rest of the application during the extraction, and the window cannot be closed by accident.
  5. When the extraction is done, the window closes and the application says, for example, “Imported: Book title.” The new book is selected in the book list.

Supported books are DAISY 2.02 (ncc.html) and DAISY 3 (.opf and .ncx) books with audio. Books that contain only text cannot be played.

The same book cannot be imported twice. If the book is already in the library, the application says: “The book … is already in the library.”

4. The library

The books are in alphabetical order. For each book you hear the title, author, duration and how much of the book you have listened to, for example “Poison, Author Name, 8 h 12 min, 35 % listened”.

  • Enter opens the selected book and starts playback from where you last stopped.
  • Ctrl+O imports new books.
  • Delete deletes the selected book. The application asks for confirmation first. Choose Yes to delete the book. Deleting removes the book files and its listening position.

5. Listening to a book

When a book opens, the application says the title of the book and the level. If you have listened to the book before, it also tells where listening continues, for example “Continuing from 1:24:10.” Playback starts right away.

  • Space: play and pause.
  • Up arrow and Down arrow: change the navigation level. See Navigation levels.
  • Left arrow and Right arrow: move back and forward on the selected level.
  • + and -: faster and slower speech. The speeds are 0.5, 0.75, 1, 1.25, 1.5, 1.75, 2, 2.5 and 3. The pitch of the voice stays the same when the speed changes.
  • N: back to normal speed (1). The application says “Speed 1, normal”.
  • U and D: volume up and down in steps of 10 percent. The application says the new value, for example “Volume 70 %”. The minimum is 10 % and the maximum 100 %, so the sound never disappears completely by accident. The volume is the same for all books, and the application remembers it.
  • T: go to time.
  • P: go to page.
  • I: tells the elapsed and remaining time, for example “Elapsed 1:24:10, remaining 6:47:50.”
  • Esc: stops listening and returns to the library.

The application remembers the listening position and speed of every book. The position is saved every few seconds while listening, and always when you return to the library or close the application.

The listening view also shows the current heading, level, speed and position in the book, for example “Position: 1:24:10 / 8:12:00”, and the volume.

6. Navigation levels

The level decides where the Left and Right arrow keys move. The Up and Down arrow keys change the level, and the application says the name of the new level. The levels are in this order:

  1. Time, 30 seconds by default. The arrow keys move the selected time back or forward. The application says nothing about the move; playback simply continues from the new point. Press I to hear the position. You can change the length of the skip in the Settings menu. A book always opens on this level.
  2. Level 1, level 2 and so on. The arrow keys move to the previous or next heading, and the application says the name of the heading. Level 2 also stops at level 1 headings, level 3 at level 1 and 2 headings, and so on. There are as many heading levels as the book has.
  3. Page, if the book has page numbers. The arrow keys move to the previous or next page.

After the last level, the Up or Down arrow returns to the first level.

When you press the Left arrow on a heading or page level, and more than 3 seconds have passed since the start of the heading, the application returns to the start of the same heading. Press the Left arrow again right away to go to the previous heading.

At the start of the book the application says “Beginning of the book” and at the end “End of the book”. If there are no more items on the level, it says “No more items on this level”.

7. Go to time and go to page

Go to time (T)

  1. While listening, press T. The Go to time window opens. It also tells the length of the book.
  2. Type the time with four digits: the first two are hours and the last two are minutes. For example, 0130 is 1 hour 30 minutes and 0005 is 5 minutes.
  3. Press Enter. Playback continues from that point.

If the time is invalid or longer than the book, the window stays open and the screen reader announces the error right away. Correct the time and press Enter again. Esc closes the window without moving.

Go to page (P)

  1. While listening, press P. The Go to page window opens. The name of the field tells the first and last page, for example “Page (1-245)”.
  2. Type the page number and press Enter.

If the page is not found, the window stays open and tells you so. If the book has no page numbers, the application says “The book has no page numbers.”

8. Creating an audio book from an e-book

Lammio Reader can make an audio book from an English EPUB, DOCX or PDF book with speech synthesis. The book must be in English, because the speech synthesis voices are English. The finished audio book can be saved in two ways:

  • as a DAISY book, which is added to the library automatically and can be played right away
  • as MP3 files in a ZIP file, for example for an ordinary MP3 player.
  1. Press Alt and choose “Create audio book” in the File menu. The Create audio book window opens.
  2. Press the “Choose book” button and choose an EPUB, DOCX or PDF file. The title and author are filled in from the book. You can change them.
  3. Choose a voice in the Voice list. The first five voices have a clear license. If the voice name ends with “not downloaded yet”, press the “Download voice” button next to the list. The screen reader announces the download progress. A voice is downloaded only once, and the download needs an internet connection. If you do not download the voice yourself, it is downloaded automatically when you listen to a sample or start creating.
  4. Before a voice is used for the first time, the license window of the voice opens. The focus is in the license field, which you can read with the arrow keys. The window first tells whether the voice may be used commercially, followed by the voice's own license file in English. Choose “I accept” if you accept the license. If you choose “I do not accept”, the voice is not downloaded or used. The license is asked only once for each voice. The “Show license” button shows the license of the selected voice again.
  5. If you like, change the speech rate, the pauses (after a comma, semicolon, colon, sentence, paragraph and heading) and the audio quality. The “Listen to sample” button plays a sample of the selected voice.
  6. Choose “Save as”:
    • “DAISY book in the library” (default): the book is added to the Lammio Reader library, and you can move by headings and pages.
    • “MP3 files in a ZIP file”: the book is saved as a ZIP file with only MP3 files, for example for an ordinary MP3 player. Every chapter is its own file, for example 001 Introduction.mp3, so the player plays them in the right order. The files also contain the book and chapter titles. The application asks where to save the ZIP file. The book is not added to the library.
    • “Both”: a DAISY book in the library and the MP3 files in a ZIP file.
  7. Press “Start creating”. The screen reader announces the progress every ten percent. If you do not want to hear the progress, clear the check box “Announce progress with the screen reader”.
  8. When the book is ready, the window closes and the application says, for example, “The audio book Book title is ready and was added to the library. Duration 6 min. Press Enter to listen.” The new book is selected in the book list. If you saved the MP3 files, the application also tells where the ZIP file was saved.

Choosing a voice

The voices are different: some are female and some are male voices, and they also differ in accent (American and British English), clarity and way of speaking. No voice is the best for everyone. The right voice depends on the book and on the listener.

So try several voices, or even all of them, before you make a long book:

  1. Make a small test file, for example a Word document where you copy a heading and a few paragraphs from the book. A small file is turned into an audio book quickly.
  2. Make an audio book from the test file with each voice you want to try. Change the book title to, for example, the name of the voice, so you can tell the versions apart in the library.
  3. Listen to the versions and choose the voice that sounds clearest and most pleasant to you. Try the speech rate and pauses at the same time.
  4. Delete the test books from the library with Delete and make the real book with the voice you chose.

The “Listen to sample” button gives you a quick idea of a voice, but the sample is only a few sentences. Listening to real text tells you better how the voice suits long listening.

Creating a long book can take a long time. You can hide the window with Esc or the “Close” button, and the creation continues in the background. Meanwhile you can listen to other books. Choose “Create audio book” again to bring the window back. “Cancel creating” stops the creation.

Your choices are saved when you start creating, so they are ready the next time.

Word books

The best result comes from a Word document whose headings have been made with Word's heading styles (Heading 1, Heading 2 and so on). Then the chapters and heading levels of the audio book are exactly the same as in the book.

If the headings have only been made bigger and bolder by hand, the application works out the headings from the font size, bold text and numbering (for example 1.2.1). The result is usually good, but sometimes a heading can go wrong, in the same way as in PDF books.

PDF books

A PDF file usually has no information about the structure of the book, so the application works out the headings from the font size and the numbering (for example 1.2.1). That is why the headings are not always as accurate as in EPUB books. The application removes page headers, footers and page numbers from the text, so they are not read out on every page.

  • If the PDF has the page numbers of the printed book, they are saved in the audio book. Then you can go to a page with P, and the navigation levels include the Page level.
  • Scanned PDF files, where the pages are only images, cannot be turned into audio books. The application then says that no readable text was found in the PDF.

9. Menus and settings

Alt opens the menu bar. There are three menus:

  • File: Import book from ZIP file, Create audio book, Delete book and Exit.
  • Settings:
    • Language: Finnish (Suomi) or English.
    • Time skip: 10 seconds, 30 seconds, 1 minute or 5 minutes.
    The choices are saved and take effect immediately, also while listening.
  • Help: Keyboard shortcuts (a list of the keys) and About (the version of the application).

Importing and deleting books work only in the library. If you try them while listening, the application says: “Press Esc to return to the library first.”

11. Troubleshooting

“The audio engine was not found.”
The file libmpv-2.dll is missing from the application folder. Without it you can import books but not listen to them. Ask the provider of the application for the file and copy it into the same folder as the application.
“Creating audio books is not available.”
The packages speech synthesis needs are missing from the application. Reinstall the application or ask its provider for help.
“Downloading the voice failed” or “The license file of the voice could not be downloaded”
Downloading a voice for the first time needs an internet connection. Check the connection and press “Download voice” again.
Creating an audio book fails, and the error message says “No readable text was found in the book”
No readable text was found in the book. Usually the reason is a scanned PDF file, where the pages are only images. Such a file cannot be turned into an audio book.
Creating an audio book fails for another reason
The full error message is copied to the clipboard. Paste it into an email with Ctrl+V and send it to the provider of the application.
“The file is not a valid ZIP file.”
The file is damaged or it is not a ZIP file. Download the book again.
“The ZIP file has no DAISY book.”
No ncc.html or .opf file was found in the ZIP file, so it is not a DAISY book.
“The book has no audio.”
The book is a text book. Lammio Reader plays only audio books.
“The file … is missing from the book.”
An audio file or another file is missing from the book. Delete the book and import it again from an intact ZIP file.

12. Where books and settings are stored

  • Extracted books are in the folder %USERPROFILE%\.lammio_reader\kirjat.
  • Listening positions, speeds, the language, the time skip, the volume, the choices for creating audio books and the accepted voice licenses are in the file %USERPROFILE%\.lammio_reader\asetukset.json.
  • The downloaded voices for creating audio books and their license files are in the folder %USERPROFILE%\.lammio_reader\aanet. One voice takes about 63 megabytes.

When you move to a new computer, you can copy the whole .lammio_reader folder. Your books, listening positions and downloaded voices move with it.
